# Публикация сайта для игроков

## Где сайт

- **Ссылка для игроков:** https://dnd-world.pages.dev
- Ссылка сразу на статью: `https://dnd-world.pages.dev/#/m/world/e/<id>`, например `…/#/m/world/e/praag`.
- Хостинг: **Cloudflare Pages**, проект `dnd-world`, основная ветка `main`.
- Аккаунт Cloudflare: toxanteloxran@gmail.com → https://dash.cloudflare.com → Workers & Pages → `dnd-world`.
- Опубликован впервые 2026-11-07.

Адреса вида `0bb25205.dnd-world.pages.dev` — снимки отдельных публикаций. Игрокам давать короткую ссылку:
она всегда показывает последнюю версию.

## Как обновить сайт

В папке проекта:

```bash
npm run deploy
```

Команда собирает версию для игроков (секреты мастера вырезаются) и заливает `dist/`. Ссылка не меняется, обновление
появляется примерно через минуту.

Если wrangler пишет, что вы не вошли: `npx wrangler@4 login` → в браузере **Authorize** → снова `npm run deploy`.

## Важно

- Публикуется только `dist/`. Исходники (`world/lore`) с секретами мастера никуда не выкладывать.
  Поэтому не GitHub Pages: бесплатно он работает только из публичного репозитория.
- Лимиты бесплатного плана: 500 публикаций в месяц, до 20 000 файлов.
- Пускать только своих (не настроено): Cloudflare Zero Trust → Access → приложение для `dnd-world.pages.dev`,
  правило «эти email». Игрок входит по коду с почты. Бесплатно до 50 человек.
