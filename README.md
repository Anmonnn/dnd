# Карта мира — интерактивная карта и энциклопедия D&D-мира

Статический сайт: карта с государствами, городами и местами, карточки при наведении,
статьи, подробные карты городов, поиск. Для мастера — редактор прямо в браузере и
секреты, которые не попадают в версию для игроков.

> В `world/` — мир автора: Центральный континент (Северные земли, Остатки Империи, Союз вольных
> городов, Государство-крепость, горы), острова варлордов, Некротический остров, Дальний Север,
> Земли Древних и Вечный Легион. Названия государств пока рабочие.
> Поверх мира автора вплетён канон Warhammer Fantasy (Total War: Warhammer III), канон автора выше.
> Что чему соответствует и что решено без автора — статья для мастера «Warhammer в нашем мире»
> (`world/lore/notes/warhammer-v-mire.md`).

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:5173 — версия мастера с редактором
```

## Как устроено

Картинка карты — только **подложка**. Всё, что меняется или реагирует на мышь, — **данные поверх**:

| Что | Где | Кто правит |
|---|---|---|
| Арт карты | `world/maps/<карта>/source.png` (или .jpg/.webp/.svg) | вы, редко |
| Границы, города, дороги, подписи | `world/maps/<карта>/features.geojson` | редактор в браузере |
| Статьи | `world/lore/**/*.md` | вы (VS Code или Obsidian) |
| Береговая линия | `world/maps/<карта>/land.geojson` | `npm run maps:land` |

Подробности и контракты — [docs/architecture.md](docs/architecture.md).

## Повседневная работа

### Поставить город или нарисовать государство
1. `npm run dev`, внизу слева — **✎ Редактор**.
2. Инструмент **●** (точка), **⬟** (область) или **〰** (линия) → кликайте по карте.
3. В окне «Что это?» — **Новая статья** (создаст `.md`-заготовку), **Существующая** или **Только подпись** (например, название моря).
4. **💾** или `Ctrl+S` — изменения записываются в `features.geojson`.

Границы между соседними государствами рисуйте точно (вершины прилипают к соседям),
а **морские края — небрежно, с заходом в море**: при сборке области обрезаются по береговой линии.
Клик по объекту в редакторе — свойства: привязка к статье, своё имя, цвет, детализация, видимость.

Надпись прямо на карте без статьи (как «Дальше живут драконы») — точка → **Только подпись** с типом «Регион».
Линия типа «Путь» рисуется пунктиром, линии других типов — сплошные (стена — «Крепость», как «Южные стены»).
Подпись области стоит неудачно — добавьте объекту в `features.geojson` свойство `"labelAt": [x, y]`
(координаты курсора показаны внизу слева в режиме мастера).

### Написать статью
Файл `world/lore/<папка>/<id>.md` (папку `world/` можно открыть в Obsidian как хранилище):

```markdown
---
name: Название города
kind: city               # типы: src/shared/kinds.ts
summary: Текст всплывающей карточки.
parent: soyuz-volnykh-gorodov
map: id-karty-goroda     # подробная карта (world/maps/id-karty-goroda)
color: "#7fa8ff"         # цвет значка на карте — по фракции/культуре; без него — цвет типа
facts:
  Расы: "люди (большинство), полурослики"   # преобладающие — первыми; сводка: notes/rasy-mira.md
  Население: 12 000
  Союз: "[[soyuz-volnykh-gorodov]]"
---
Текст со ссылками: [[gosudarstvo-krepost|Государство-крепость]] держит стены.

> [!dm] Секрет мастера
> Игроки этого не увидят.
```

`visibility: dm` во фронтматтере скрывает от игроков всю статью вместе с объектом на карте.

Картинки в тексте — как в Obsidian: `![[рисунок.png]]` или `![[рисунок.png|300]]` (ширина), а также `![](рисунок.png)`.
Файл ищется рядом со статьёй, затем от `world/`, затем по имени во всей папке `world/`.

### Персонаж на карте (кружок с аватаром)
Персонаж «живёт» в каком-то месте — у этого места на карте появляется кружок с его аватаром и именем.
Клик по кружку открывает всю статью персонажа.

**Из браузера** (`npm run dev`):
- откройте статью места → в блоке «Мастер · правка» впишите имя → **+ Персонаж здесь**;
- в статье персонажа: **📍 Привязать к месту** → кликните по месту на карте (Esc — отмена);
- **🖼 Аватар…** — выбрать картинку (PNG/JPEG/WebP/GIF до 15 МБ), она сохранится в `world/media/avatars/`.

**Вручную** — во фронтматтере статьи (шаблон: `world/lore/_templates/character.md`):

```yaml
location: soyuz-volnykh-gorodov   # id, название или "[[Ссылка]]" места
avatar: портрет.png               # рядом со статьёй, от world/ или "[[портрет.png]]"
```

Если самого места нет на этой карте, кружок встаёт у ближайшего «родителя» (таверна → город → государство).
У одного места помещается 5 кружков в ряд, остальные сворачиваются в «+N» — список в статье места
(«Здесь находятся»). Слой «Персонажи» можно выключить в меню слоёв.
Для карты сайт делает уменьшенные копии картинок, так что огромные портреты страницу не тормозят.

### Группы игроков на карте
Группа — статья с `kind: party` (шаблон: `world/lore/_templates/party.md`). Где у неё `location`, там на карте стоит
**знамя**: фото группы (или инициалы) в двойном кольце её цвета, флажок, название и ряд аватаров участников.

```yaml
kind: party
location: monlak        # где группа сейчас — перенесли сюда другое место, знамя переехало
avatar: группа.png      # фото группы
color: "#ff8a3d"        # цвет знамени
```

Участники — обычные статьи персонажей с `parent: <id группы>` и своим `avatar`; `location` им не нужен. Групп может быть
сколько угодно — у каждой своё знамя. Переместить группу из браузера: статья группы → **📍 Привязать к месту** → клик
по месту на карте. Знамёна выключаются вместе со слоем «Персонажи». Группу, о которой игрокам знать нельзя, —
`visibility: dm`.

**Фото** есть у любой статьи: `avatar` (кружок на карте и в карточке, в браузере — кнопка **🖼 Аватар…**)
и `image` (большая картинка в начале статьи).

### Подробная карта города или региона
1. Папка `world/maps/<id>/`: `source.png` (или `.svg`) и `map.json`:
   `{ "title": "<Город> — план города", "source": "source.png", "entity": "<id города>", "parent": "world" }`
2. В статье города — `map: <id>`.
3. `npm run maps` нарежет тайлы. Объекты на новой карте ставятся тем же редактором.

### Заменить арт на более качественный
Положите новую картинку вместо `source.png` (той же композиции) — запущенный `npm run dev` сам перенарежет тайлы,
**все объекты останутся на местах**: координаты привязаны к пространству `size` из `map.json`, а не к пикселям.
Если поменялась береговая линия — `npm run maps:land -- world --debug` и проверьте `world/maps/world/land-debug.png`.

### Приближение и детальный арт (врезки)
Картинка резкая только до своего разрешения: 1461 px карты мира начинают мылиться сразу после масштаба 1:1.
Поэтому арт многоуровневый:

1. **Обзор** — арт карты мира.
2. **Врезки** — отдельный детальный арт на регион. Лежит ровно поверх своего места и плавно проявляется
   при приближении; края растушёваны, шва не видно. Клик по государству или региону разворачивает его
   на весь экран — там врезка уже видна. Кнопка ⤢ у зума возвращает всю карту.
3. **Подробные карты** (города и т. п.) — отдельные карты, открываются двойным кликом (`map:` в статье).

Как сделать врезку:

```bash
npm run maps:inset -- world ostrova-varlordov          # регион по id статьи
npm run maps:inset -- world sever --entity=severnye-zemli,dalniy-sever --title="Север"
npm run maps:inset -- world zaliv --bounds=400,700,300,200   # или явная рамка [x, y, ширина, высота]
```

В `world/maps/world/insets/<id>/` появятся `inset.json` (рамка в пропорциях 3:2, 1:1 или 2:3 — как генерирует
нейросеть), `reference.png` (вырезка карты — образец) и `prompt.txt` (готовый промпт). Отдайте образец
нейросети (например, ChatGPT: «перерисуй с большей детализацией»), результат сохраните рядом как `source.png` —
`npm run dev` сам нарежет его. Чем больше картинка, тем глубже можно приблизить: прогоните результат через
апскейлер ×4 ([Upscayl](https://upscayl.org), бесплатный) — 6144×4096 вместо 1536×1024.

Ровно ли легла врезка, видно в меню слоёв → «Врезки: проверка совмещения» (контуры и полупрозрачный арт).
Если нейросеть сдвинула берега, подвиньте `bounds` в `inset.json` — тайлы перенарежутся сами.
Поля `inset.json`: `showFrom` — с какого зума врезка видна полностью, `feather` — ширина растушёвки (доля, 0.08).

## Мастер и игроки

| Команда | Кому | Что внутри |
|---|---|---|
| `npm run dev` | мастеру | всё + редактор + список проблем (⚠ в шапке) |
| `npm run dev:public` | проверить | как увидят игроки |
| `npm run build` → `dist/` | игрокам | секреты вырезаны ещё при сборке |
| `npm run build:dm` → `dist-dm/` | мастеру | полная версия без редактора |

## Публикация для игроков

> **Сайт опубликован:** https://dnd-world.pages.dev — обновить: `npm run deploy`.
> Всё о публикации (аккаунт, ссылки, что делать, если забыли) — [docs/publishing.md](docs/publishing.md).

`dist/` — обычные статические файлы (сейчас ~2,5 МБ и ~100 файлов). Работают из любой папки и на любом
хостинге: пути относительные, адреса статей — после `#`, так что ссылку прямо на статью можно кидать игрокам
(`…/#/m/world/e/praag`). Секреты мастера в `dist/` не попадают — их вырезает сборка.

**Важно:** публикуйте только `dist/`, а не исходники. В `world/lore` лежат блоки `> [!dm]` и статьи `visibility: dm` —
любой, у кого есть доступ к исходникам, прочитает все секреты.

### Cloudflare Pages — рекомендуемый способ (бесплатно)
Бесплатный план: 500 публикаций в месяц, до 20 000 файлов на сайт; лимита на трафик статики в документации нет.
Сайт заливается с вашего компьютера, исходники никуда не уходят.

1. Зарегистрируйтесь на [cloudflare.com](https://dash.cloudflare.com/sign-up) (бесплатно).
2. Один раз: `npx wrangler@4 login` — откроется браузер, подтвердите вход.
3. Один раз: `npx wrangler@4 pages project create dnd-world --production-branch=main` — проект и адрес
   `https://dnd-world.pages.dev` (если имя занято — Cloudflare добавит суффикс и покажет итоговый адрес).
4. `npm run deploy` — соберёт версию для игроков и опубликует её на этот адрес.
5. Поменяли мир — снова `npm run deploy`, ссылка та же.

Другое имя проекта — поменяйте `dnd-world` и в шаге 3, и в скрипте `deploy` в `package.json`.

Без терминала: панель Cloudflare → Workers & Pages → Create → Pages → **Upload assets** → перетащите папку `dist`
после `npm run build` (так — до 1000 файлов).

**Только для своих (по желанию):** Cloudflare Zero Trust → Access → приложение для адреса сайта с правилом «эти email».
Игрок вводит почту и получает одноразовый код. Бесплатно до 50 пользователей.

### Другие варианты
- **GitHub Pages** — готов `.github/workflows/deploy-pages.yml` (Settings → Pages → Source: GitHub Actions), но на
  бесплатном GitHub Pages работает только из **публичного** репозитория — исходники с секретами будут видны всем.
- **Netlify** — бесплатный план теперь на кредитах: 300 в месяц, публикация — 15, 1 ГБ трафика — 20. Небольшой группе
  хватит, но когда кредиты кончаются, сайт отключается до следующего месяца. Без терминала: Netlify Drop — перетащить `dist`.

## Команды

| | |
|---|---|
| `npm run maps [-- <id>] [--force]` | нарезать тайлы (инкрементально; само запускается в dev/build) |
| `npm run maps:land -- <id> [--debug]` | построить береговую линию по арту |
| `npm run check` | проверить данные мира в обоих режимах |
| `npm run deploy` | собрать версию для игроков и опубликовать на Cloudflare Pages |

| `npm run screenshot -- <url> --out=shot.png` | скриншот через установленный Edge |

## Советы по арту
- Нынешняя карта 1461×1077 — при сильном приближении мылится. Прогоните её через апскейлер ×4
  (бесплатный [Upscayl](https://upscayl.org), модели Real-ESRGAN) и положите вместо `source.png`.
- Не рисуйте на арте подписи, границы и значки городов — они живут в данных.
- Планы городов и деревень удобно делать в генераторах [watabou](https://watabou.github.io/)
  (экспорт PNG/SVG) — без текста; подписи ставьте в редакторе.
