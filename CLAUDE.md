# DnD world — интерактивная карта и энциклопедия мира

Общаемся по-русски. Комментарии в коде — по-русски и коротко, идентификаторы — по-английски.

## Главное
- Архитектура и контракты: `docs/architecture.md`. Прочитай перед изменениями.
- Арт (`world/maps/*/source.*`) — только подложка. Границы, города, подписи — данные (`features.geojson` + `world/lore/**/*.md`). Ничего не «запекать» в картинку.
- Мир — авторский (`world/lore`). Ничего не выдумывать от себя: ни государств, ни сюжета, ни имён. Можно только развивать идеи автора — и каждое такое дополнение явно называть в ответе.
- По просьбе автора в мир вплетён канон Warhammer Fantasy (TW3); канон автора выше. Соответствия и решения без автора — `world/lore/notes/warhammer-v-mire.md` (держать в актуальном виде). Отсылки к Warhammer — только в блоках `> [!dm]`, игроки видят лишь мир.
- У регионов, государств и поселений всегда указывать факт «Расы» — преобладающие расы, самые многочисленные первыми (по лору D&D и Warhammer). Сводка «кто где живёт» — `world/lore/notes/rasy-mira.md`, держать в актуальном виде; у каждой основной расы D&D должно быть место.
- Местам фракций и культур давать `color` — значок на карте красится в цвет хозяев (палитра — в `warhammer-v-mire.md`, раздел «Цвета на карте»). Нейтральные места — без цвета.

## Где что
- `src/shared/` — изоморфные контракты (типы, zod-схемы, реестр типов `kinds.ts`, математика зума `zoom.ts`). Без Node API и DOM.
- `tooling/world/` — компилятор `world/` → `virtual:world`, Vite-плагин, dev-API редактора, `npm run check`.
- `tooling/maps/` — нарезка тайлов (`npm run maps`), маска суши (`npm run maps:land -- <mapId>`), детальные врезки (`npm run maps:inset -- <mapId> <insetId>`; нарезка — `insets.ts`).
- Глубина зума держится на арте: арт карты — обзор, врезки (`world/maps/*/insets/*/source.png`) — детали при приближении. Сам арт рисует автор; мы готовим образец, рамку и нарезку.
- `src/app/map/MapController.ts` — движок Leaflet (CRS: `LatLng(y, x)`, y вниз); `src/app/editor/` — dev-редактор на Geoman.

## Команды
- `npm run dev` — мастерская версия + редактор; `npm run dev:public` — глазами игроков.
- `npm test`, `npm run typecheck`, `npm run check` — перед завершением работы.
- `npm run screenshot -- <url> --out=<png> --do=…` — скриншот через установленный Edge (см. шапку `tooling/dev/screenshot.ts`).

## Правила
- Новый тип сущности — только в `src/shared/kinds.ts`.
- Секреты мастера (`visibility: dm`, `> [!dm]`) вырезаются компилятором при сборке для игроков — не прятать их через CSS.
- Изменил `src/shared/zoom.ts` → перегенерировать тайлы: `npm run maps -- --force`.
- `public/generated/`, `dist*` — генерируются, в git не храним.
